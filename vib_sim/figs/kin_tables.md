# 베이스 자세 보상 — 조건 격자 (2026-11-24, 시뮬레이션)

위아래 동작(2번 관절 ±5°, 실측 기록) 중 출발 → 턱·패인 바닥 → 정지. 월드 기준으로 직선에서 벗어난 거리[mm]. 위쪽 여덟 줄은 토크 제어 + 추종 제어기(J1–3), 아래 여섯 줄은 위치 제어(엔코더 재생, 모터가 보정을 그대로 따라감).
자세 보상 = 베이스의 들림·기울기를 관절 1–3으로 되돌림(베이스 자세는 참값). 비는 대책 없음 대비, 씨앗 2·3을 뺀 여섯 조건의 가운데 값(범위).
